# 📊 Customer Churn Prediction with XAI

An end-to-end machine learning project that predicts customer churn using **XGBoost** and provides interpretable insights using **SHAP Explainable AI**.

## 🚀 Live Demo

👉 **Streamlit App:** [My_STREAMLIT_APP_LINK](https://customer-churn-prediction-xai-dadpqqzrufzo8syaorhb2n.streamlit.app/)

## 📌 Project Overview

This project predicts whether a customer is likely to churn based on customer demographics, tenure, charges, contract type, and payment method.

The application provides:

* 🔮 Churn prediction
* 📊 Churn probability
* 🧠 SHAP-based Explainable AI
* 🌐 Interactive Streamlit web app
* 🚀 Live deployment

## 📈 Model Performance

Three machine learning models were evaluated:

* Logistic Regression
* Random Forest
* XGBoost

**Best Model: XGBoost**

* **ROC-AUC:** 0.8054
* **Accuracy:** ~76.1%

## 🧠 Explainable AI

The application uses **SHAP (SHapley Additive exPlanations)** to explain individual predictions.

SHAP helps identify which customer features contributed to increasing or decreasing the predicted churn risk.

This makes the model more interpretable and helps understand **why a customer is predicted to churn**.
